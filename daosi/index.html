安装说明

  • 安卓：下载后打开 APK；首次需要在 设置 › 安全 里允许"安装未知来源应用"。
  • Windows：双击 MSI 安装。暂未购买代码签名证书，如出现 SmartScreen 提示，点"更多信息 › 仍要运行"。
  • macOS：打开 DMG，把道生一拖进"应用程序"。暂未公证，首次打开请在 系统设置 › 隐私与安全性 里点"仍要打开"。
  • iOS：测试版 暂无 Apple 开发者签名，需要用 AltStore / Sideloadly 等工具以你自己的 Apple ID 签名后安装（免费 Apple ID 签名 7 天有效）。
  • 首次使用：在「修为 › 法宝库」下载语音识别模型和词库（建议 Wi-Fi）。

各平台功能

  • 安卓：完整功能（晨钟锁屏跟读、语音识别、本地大模型、功法、修炼场、藏经阁、同步）。
  • Windows / macOS / iOS：首批提供 洞府、日程与待办、修为；功法、语音与藏经阁陆续上线。

隐私

无账号、无广告、无统计。数据默认只保存在你的设备上；语音识别和本地大模型都在设备上运行。可选同步只去你自己的 GitHub 私有仓库或网盘。
